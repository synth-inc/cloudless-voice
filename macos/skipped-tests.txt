# Tests the default test plan (macos/Onit.xctestplan) skips, one per line, each with a reason.
#
# A clean checkout (a contributor's machine or a CI runner) has no downloaded
# models, no ~/Documents data, no transcription history, and in the fully open
# build no TranscriptionCleanup library. A test that needs any of those is listed here.
#
# Format: `Suite` or `Suite/testMethod()`, then `# reason`.
# After editing, run `scripts/check-ci-testplan.py --write` to update the plan.
# CI runs `scripts/check-ci-testplan.py` to make sure the two agree.
#
# xcodebuild ignores the plan's skippedTests for Swift Testing tests (most of these),
# so scripts/ci-test.sh also passes every line as a -skip-testing flag. Run the plan
# through scripts/ci-test.sh, not from Xcode, which would still run them.

WhisperCoreMLASRServiceTests               # drives WhisperCoreMLEngine.shared
